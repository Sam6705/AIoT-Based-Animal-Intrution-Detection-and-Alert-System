# 🐾 AIoT-Based Animal Intrusion Detection and Alert System

## 📌 Overview

The **AIoT-Based Animal Intrusion Detection and Alert System** is an intelligent solution designed to enhance road safety by detecting animals in real-time using advanced computer vision and deep learning techniques. By integrating Artificial Intelligence with IoT concepts, this system enables proactive monitoring and alert mechanisms to reduce vehicle–animal collisions, particularly in low-visibility and night-time conditions.

---

## 🎯 Key Features

* 🚀 Real-time animal detection using deep learning
* 🌙 Effective performance in low-light environments
* 📡 Integration of AI with IoT for smart monitoring
* ⚡ Fast object detection using Tiny YOLOv2
* 🔔 Alert generation upon detecting animal intrusion

---

## 🛠️ Technologies Used

* Python
* OpenCV
* NumPy
* Tiny YOLOv2 (Deep Learning Model)
* Computer Vision
* AIoT (Artificial Intelligence of Things)

---

## ⚙️ System Workflow

1. Capture live video feed or input footage
2. Preprocess frames using OpenCV
3. Apply Tiny YOLOv2 model for object detection
4. Identify animals with bounding boxes
5. Trigger alert mechanism upon detection
